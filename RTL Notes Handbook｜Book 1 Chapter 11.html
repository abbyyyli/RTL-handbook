重要句型

01

詢問數量

A + มีกี่ + classifier + คะ
A + mii gìi + classifier + khá
How many units does A have?
A有多少單位？
หนึ่งปีมีกี่เดือนคะ
nʉ̀ng bpii mii gìi dʉan khá
How many months does one year have?
一年有幾個月？
หนึ่งปีมีสิบสองเดือนค่ะ
nʉ̀ng bpii mii sìp-sɔ̌ɔng dʉan khâ
One year has twelve months.
一年有十二個月。
02

詢問持續多久

คุณ + V. + Object + นานเท่าไรคะ
khun + V. + Object + naan thâo-rài khá
How long do you do something?
你做某件事做多久？
คุณเรียนภาษาไทยนานเท่าไรคะ
khun riian phaa-sǎa thai naan thâo-rài khá
How long do you study Thai?
你學泰文學多久？
เรียนภาษาไทยหนึ่งชั่วโมงค่ะ
riian phaa-sǎa thai nʉ̀ng chûa-moong khâ
I study Thai for one hour.
我學泰文一個小時。
03

詢問到目前為止已經多久

คุณ + V. + Object + กี่ + time unit + แล้วคะ
khun + V. + Object + gìi + time unit + lɛ́ɛw khá
How long have you been doing it already?
你已經做了多久了？
คุณเรียนภาษาไทยกี่ชั่วโมงแล้วคะ
khun riian phaa-sǎa thai gìi chûa-moong lɛ́ɛw khá
How many hours have you studied Thai already?
你已經學泰文幾個小時了？
เรียนภาษาไทยหนึ่งชั่วโมงแล้วค่ะ
riian phaa-sǎa thai nʉ̀ng chûa-moong lɛ́ɛw khâ
I have studied Thai for one hour already.
我已經學了一個小時的泰文。
04

詢問還要多久

คุณจะ + V. + Object + อีกกี่ + time unit + คะ
khun jà + V. + Object + ìik gìi + time unit + khá
How much longer will you do it?
你還要做多久呢？
คุณจะเรียนภาษาไทยอีกกี่ชั่วโมงคะ
khun jà riian phaa-sǎa thai ìik gìi chûa-moong khá
How many more hours will you study Thai?
你還要再學幾個小時的泰文？
จะเรียนภาษาไทยอีกหนึ่งชั่วโมงค่ะ
jà riian phaa-sǎa thai ìik nʉ̀ng chûa-moong khâ
I will study Thai for one more hour.
我會再學泰文一小時。
05

詢問或說明什麼時候

คุณ + V. + Object + เมื่อไรคะ
khun + V. + Object + mʉ̂a-rai khá
When did you do it?
你在何時做這件事？
คุณจะ + V. + Object + เมื่อไรคะ
khun jà + V. + Object + mʉ̂a-rai khá
When will you do it?
你何時會這樣做？
คุณเรียนภาษาไทยเมื่อไรคะ
khun riian phaa-sǎa thai mʉ̂a-rai khá
When did you study Thai?
你什麼時候學過泰文？

2. 跟朋友約週末逛街：星期幾去？

Friend
เสาร์นี้ว่างไหมคะ
sǎw níi wâang mái khá
Are you free this Saturday?
你這星期六有空嗎？
You
ว่างค่ะ จะไปไหนคะ
wâang khâ, jà bpai nǎi khá
I’m free. Where are we going?
我有空，要去哪裡？
Friend
ไปห้างไหมคะ
bpai hâang mái khá
Do you want to go to the mall?
要去逛百貨公司嗎？
You
ได้ค่ะ อยากจะซื้อของ แล้วก็ดูของค่ะ
dâai khâ, yàak jà sʉ́ʉ khɔ̌ɔng, lɛ́ɛw gɔ̂ɔ duu khɔ̌ɔng khâ
Okay. I want to shop and look around.
好啊，我想逛街買東西。
Friend
ไปกี่ชั่วโมงดีคะ
bpai gìi chûa-moong dii khá
How many hours should we go for?
我們去幾個小時？
You
ไปสองชั่วโมงก็ได้ค่ะ
bpai sɔ̌ɔng chûa-moong gɔ̂ɔ dâai khâ
Two hours is fine.
兩個小時就好。
