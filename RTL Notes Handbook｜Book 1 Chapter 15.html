02

本課句型：Please say it again / slower / louder

พูดอีกทีสิคะ
phûut ìik thii sì khá
Please say it one more time.
請再說一次。

請說慢一點。
พูดดัง ๆ หน่อยค่ะ
phûut dang-dang nɔ̀i khâ
Please speak louder.
請說大聲一點。
03

本課句型：Help do something for me

ช่วย + V. + Object + ให้ + หน่อยค่ะ
chûai + V. + Object + hâi + nɔ̀i khâ
Please help do something for me.
請幫我做一些事。
ช่วยเปิดประตูให้หน่อยค่ะ

ช่วยเปิดแอร์ให้หน่อยค่ะ
chûai bpə̀ət ɛɛ hâi nɔ̀i khâ
Please help turn on the air conditioner for me.
請幫我開冷氣。
04

本課句型：Can you help me...?

ช่วย + V. + Object + ให้หน่อยได้ไหมคะ
chûai + V. + Object + hâi nɔ̀i dâai mái khá
Could you help do something for me?
你能幫我做些什麼嗎？
ช่วยเปิดประตูให้หน่อยได้ไหมคะ
chûai bpə̀ət bprà-dtuu hâi nɔ̀i dâai mái khá
Could you help open the door for me?
可以幫我開門嗎？
ได้ค่ะ
dâai khâ
Sure.
可以。
05

本課句型：Short request without ให้

ช่วย + V. + Object + หน่อยค่ะ
chûai + V. + Object + nɔ̀i khâ
Please help do something.
請幫我做一些事情。

請按輕一點。
