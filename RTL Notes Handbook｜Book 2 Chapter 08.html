重要句型

01

Structure｜N อยู่ที่ไหน？東西在哪裡？

N อยู่ที่ไหนคะ/ครับ
N yùu thîi-nǎi khá/khráp
Where is N?
N 在哪裡？
แก้วอยู่ที่ไหนคะ
gɛ̂ɛw yùu thîi-nǎi khá
Where is the glass?
杯子在哪裡？
แก้วอยู่บนโต๊ะค่ะ
gɛ̂ɛw yùu bon dtó khâ
The glass is on the table.
杯子在桌上。
02

Structure｜วาง N ไว้ + Position：把東西放在……

Subject + วาง + N + ไว้ + Position + Place
Subject + waang + N + wái + Position + Place
Subject puts N at a position/place.
主詞把 N 放在某個位置／地點。
ฉันวางถ้วยไว้บนโต๊ะค่ะ
chǎn waang thûai wái bon dtó khâ
I put the cup on the table.
我把杯子放在桌子上。
วางไว้ตรงนี้ได้เลยค่ะ
waang wái dtrong-níi dâai ləəy khâ
You can put it right here.
放在這裡就可以。
03

Structure｜เก็บ N ไว้ใน N：把東西收進……

Subject + เก็บ + N1 + ไว้ใน + N2
Subject + gèp + N1 + wái nai + N2
Subject keeps N1 inside N2.
主詞把 N1 收在 N2 裡。
ฉันเก็บเสื้อผ้าไว้ในตู้เสื้อผ้าค่ะ
chǎn gèp sʉ̂a-phâa wái nai dtûu-sʉ̂a-phâa khâ
I keep clothes in the wardrobe.
我把衣服放在衣櫃裡。
เก็บนมไว้ในตู้เย็นนะคะ
gèp nom wái nai dtûu-yen ná khá
Keep the milk in the fridge.
把牛奶放在冰箱裡。
04

Structure｜ใช้ + Body Part + Verb：用某身體部位做動作

Subject + ใช้ + Body Part + Verb + Object
Subject + chái + Body Part + Verb + Object
Subject uses a body part to do something.
主詞用某個身體部位做某件事。
เราใช้หูฟังเสียงค่ะ
rao chái hǔu fang sǐang khâ
We use ears to listen to sounds.
我們用耳朵聽聲音。
เราใช้ตาดูค่ะ
rao chái dtaa duu khâ
We use eyes to see.
我們用眼睛看。
